ORDO FIDÉLITÉ CATHOLIQUE — INSTALLATION GITHUB/ANDROID

1. Décompressez ce ZIP.
2. Envoyez index.html, manifest.webmanifest, sw.js et icon.svg à la racine du dépôt GitHub ordo-liturgique.
3. GitHub Pages : Settings > Pages > Deploy from a branch > main > /(root).
4. Sur Android, ouvrez le site dans Chrome.
5. Menu ⋮ > Ajouter à l'écran d'accueil / Installer l'application.
